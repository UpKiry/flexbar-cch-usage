# Flexbar CC Hub 用量插件

这是一个用于 Flexbar/FlexDesigner 的 Claude Code Hub 用量仪表盘插件。它通过 CC Hub 的登录 API 获取配额、今日用量、日期汇总和按需的最近调用记录，并在 Flexbar 上显示配额和用量两个固定按键。按键使用插件自绘 PNG 和内嵌 CJK 字体，避免原生标题布局重叠或中文缺字：

当前版本：`1.5.0`

- 配额（固定 5 小时周期）
- 用量（按键配置可选 5h、1d、7d、1m，默认 1d）

插件启动、设备连接和按键点击时会刷新数据，默认每 60 秒自动刷新一次。网络或 API 失败时保留最后一次成功数据，并标记“数据过期”。

## 配置

在 FlexDesigner 的插件配置页填写：

- `CC Hub URL`：你的 CC Hub 部署地址（支持带子路径的部署，例如 `https://host/cc-hub`）
- `API Key`：可用于网页登录的用户 API Key
- 刷新间隔（秒）：范围 15～3600，默认 60；留空按 60 处理

在 FlexDesigner 中打开“用量”按键配置，可以为每个按键单独选择时间范围：

- `5 小时`：显示 quota 当前消费金额
- `1 天`：今日调用次数和金额
- `7 天`：最近 7 天调用次数和金额
- `30 天`：最近 30 天调用次数和金额

同一配置页还可以选择按键指标：

- `调用次数与成本`（默认）：显示请求数和金额。
- `输入与输出 Token`：显示输入、输出 Token 总量。
- `缓存读写`：显示缓存读取和创建 Token。
- `最近调用`：读取最近一页最多 8 条调用，显示数量和最新模型。
- `日期汇总`：使用 `stats-summary` 的请求数和成本汇总，适合需要完整日期统计的场景。

`5 小时` 范围只有配额接口提供数据，其它指标在该范围下会被禁用。

“最近调用”会按需读取调用明细的第一页；没有配置该指标时不会请求调用明细接口。一次刷新会合并相同时间范围的汇总请求，避免因多个按键重复访问 CC Hub。

“配额”按键固定使用 5 小时周期，并显示当前使用金额与配额上限（例如 `$8.40 / $10.00`）。

API Key 只保存在 FlexDesigner 配置和本机权限受限的恢复副本中，不会写入按键数据或日志。插件是自包含的，不依赖上一级 `cch-usage` 目录。

保存成功的配置还会在用户目录的 `.flexbar-cch-usage/config.json` 中保留一份权限受限的恢复副本。插件重新安装后会自动恢复该副本并刷新按键；删除该文件即可清除恢复副本。

## 架构

四个模块各自只做一件事，便于单独测试：

| 模块 | 职责 |
| --- | --- |
| `src/core.js` | 纯逻辑：配置归一化、接口字段归一化、按键视图模型 `buildView`。按键图片和按键标题共用同一份视图模型，不会出现两处显示不一致。 |
| `src/hub-client.js` | 数据抓取：登录会话、按接口隔离的失败处理、超时与总时限、登录冷却、本地时区的日期窗口。 |
| `src/render.js` | 绘制：先算便宜的指纹，指纹变了才画布编码；字体缺失时降级而不是抛异常。 |
| `src/runtime.js` | 编排：设备登记表、按键代次隔离、后台刷新、绘制队列、失败退避的定时器。 |

关键约定：

- **宿主事件立刻返回。** `plugin.alive` 等事件的处理器只记账并触发后台刷新，绝不在回调里等网络，否则宿主会一直等下去。
- **按接口隔离。** 一个接口失败只让用到它的按键过期，其它按键照常更新。
- **按设备隔离。** 每台设备一份按键列表和一个代次，设备拔出时在途绘制作废，重新插入后能自己画回来。
- **失败要退避。** 连续失败时刷新间隔按倍数拉长，最长 8 倍，避免接口挂掉时把 CC Hub 打满。

## 开发

环境要求：Node.js 18+、FlexDesigner 1.3+、Flexbar。自绘渲染使用 `@napi-rs/canvas`，按键目标尺寸为 240×60；设备返回 180px 宽度时自动使用紧凑布局。构建时会固定把 macOS arm64 与 Windows x64 的 canvas 原生模块同步到插件包；本地已安装则直接复用，缺失时（例如 Linux CI）由 `npm pack` 自动下载，因此原生二进制无需入库。

~~~bash
npm install
npm run build
npm run plugin:validate
npm run dev
~~~

打包和安装：

~~~bash
npm run plugin:pack
npm run plugin:install
~~~

> `flexcli` 使用了 `assert { type: "json" }` 导入语法，在 Node.js 22 及以上会直接报错。执行 `plugin:validate` / `plugin:pack` 时请使用 Node.js 20，或等待 `flexcli` 升级。

## API 行为

插件使用以下 CC Hub 接口：

- `POST /api/auth/login`
- `GET /api/v1/me/quota`
- `GET /api/v1/me/today`
- `GET /api/v1/me/usage-logs/stats-summary`
- `GET /api/v1/me/usage-logs`（仅配置“最近调用”指标时读取最近一页，最多 8 条；客户端另提供完整分页方法）

`today`、`7d` 和 `1m` 只会在存在对应范围且需要汇总数据的用量按键时请求；相同范围的请求会在一次刷新中合并。最近调用只在存在对应指标时请求，并保留 `recentLogs` 与 `recentSummary` 缓存供按键渲染。配置页的“测试连接”只做一次轻量连通性检查（登录 + 一次配额查询），不会保存。

登录 Cookie 在插件进程内复用；401 会重新登录一次，即使响应体不是 JSON。查询类 GET 请求默认超时 15 秒，整轮抓取还有 40 秒总时限，遇到网络错误或 429/500/502/503/504 会按 `Retry-After` 和指数退避重试一次；登录 POST 不重试，登录失败会进入冷却，不会每轮都去撞登录接口。
